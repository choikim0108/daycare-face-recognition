어린이집 얼굴 인식 자동 분류기 — 검수 분리 버전

1. 준비
run.bat을 실행합니다. 최초 설치에는 인터넷이 필요하며, 얼굴 모델의 첫 실행에는 모델 파일 다운로드가 필요할 수 있습니다.
기준, 원본, 결과 폴더를 각각 선택합니다. 세 폴더는 서로 달라야 하며, 한 폴더가 다른 폴더 안에 있어도 안 됩니다.
예: 사진작업/기준, 사진작업/원본, 사진작업/결과
기준 폴더 안에 아동별 이름의 폴더를 만들고, 올바른 아동의 얼굴이 선명한 사진을 넣어주세요.
기존 기준 폴더는 자동 정리·삭제하지 않습니다. 과거 버전에서 잘못 분류된 사진이 이미 섞여 있다면 사람이 먼저 확인해야 합니다. 이 업데이트만으로 과거 기준 오류가 사라지지 않습니다.

2. 자동 분류
엄격도 슬라이더(0.20~0.80, 기본 0.45)를 조정하고 사진 분류 시작을 누릅니다.
기준 임베딩은 아동별 최신 수정 시간 기준 최대 20장으로 계산합니다. 20장을 넘는 기존 사진도 삭제하지 않습니다.
결과는 결과/아동명에 복사됩니다. 단체 사진은 일치하는 여러 아동의 결과 폴더에 각각 복사됩니다.
탐지 실패·일치 없음은 결과/미분류(Unknown)에 보존됩니다.
원본은 이동·수정·삭제하지 않습니다. 파일명이 겹치면 _1, _2 등의 새 이름으로 보존합니다. 재실행하면 결과 사본이 추가될 수 있습니다.
결과 폴더는 자동으로 학습에 사용되지 않습니다.
분류 결과 폴더에는 용도 표시 파일(.daycare-classification-results)이 생성됩니다. 이후 실행에서도 이 폴더나 하위 폴더를 원본·기준으로 재사용하면 거절합니다. 표시 파일을 임의로 삭제하거나 결과 사진을 기준 폴더로 직접 복사하면 이 보호를 우회하므로 하지 마세요. 구버전 결과에는 표시 파일이 없을 수 있습니다.

3. 검수 및 수정
검수 탭에서 결과 폴더를 조회하고 사진을 클릭해 선택합니다.
목적지 아동을 선택하고 '선택 사진 이동'을 누르면 해당 결과 사본만 이동합니다. 원본과 다른 아동에게 배분된 단체 사진 사본은 유지됩니다.
미분류 사진도 올바른 아동의 결과 폴더로 이동할 수 있습니다.
기준 사진에 등록할 새 아동은 기준 폴더에 해당 이름의 폴더를 먼저 만들고 새로고침하세요.
영구삭제 기능은 제공하지 않습니다.

4. 기준에 명시적으로 추가
이동만으로는 기준에 반영되지 않습니다.
올바른 아동 결과 폴더에서 사진을 선택하고 '선택 사진을 현재 아동의 기준으로 승인'을 누릅니다.
확인창에서 유일한 얼굴이 해당 아동임을 직접 확인한 뒤 승인합니다.
얼굴 탐지가 정확히 하나인 사진만 기준 폴더로 복사됩니다. 단체 사진·얼굴 없음·탐지 실패는 거절합니다. 단체 사진의 가장 큰 얼굴을 다른 아동의 기준으로 넣는 위험을 피하기 위한 제한입니다.
이는 자동 신원 검증이 아닙니다. 잘못된 아동을 사용자가 승인하면 기준에 오류가 생길 수 있습니다.
승인 성공·실패 개수를 확인하세요. 일부 실패해도 이미 성공한 복사는 유지됩니다. 결과와 원본은 보존됩니다.
승인한 기준 사진은 다음 분류 실행부터 반영됩니다. 반복 승인하면 별도 사본이 추가될 수 있습니다.

5. 주의와 검증 범위
이 버전은 얼굴 인식 정확도 자체의 개선을 입증하지 않습니다. 실제 아동 사진을 사용한 검증은 수행하지 않았습니다.
실제 사진 없이 임시 파일·임베딩 모킹으로 저장 분리, 승인, 이동, 충돌, 단체 사진 배분, 폴더 혼용 방지를 검증합니다.
구버전 배포용 ZIP은 갱신되지 않았습니다. 이 소스 폴더의 run.bat을 사용하세요.
분류·검수 중 외부에서 폴더를 이동하거나 연결 경로를 바꾸지 마세요.
